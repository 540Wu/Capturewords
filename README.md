# 错词捕手（Cuoci）

一个 Android 小工具：自动记录你在「不背单词」里答错或不认识的单词，每天把它们编成一篇英语小短文，帮你在语境里记住它们。

> 个人自用项目，侧载安装，不上架应用商店。

---

## 它解决什么问题

背单词时「答错、点模糊、点忘记了」的那些词，通常没人帮你回头复习。
这个 App 通过无障碍服务把它们悄悄抓下来，攒到晚上用 AI 生成一篇包含这些词的小短文——
**你只要读短文，就能顺便复习今天没记住的词。**

## 功能

- **自动抓词**：监听「不背单词」的界面，自动记录以下情况的单词
  - 选择题选错（看英文选中文）
  - 点「看答案」
  - 自评题点「模糊 / 忘记了」
  - 答对、点「认识」的词**不会**被记录
- **音标 + 释义**：抓词时顺手存下，旧词可一键用 AI 补全
- **错词列表**：按天分组，点单词可看释义、听发音
- **复习自测**：卡片式回忆，自评「记住了 / 没记住」，没记住的可再来一轮
- **AI 短文**：错词每 8 个一组，生成 50–100 词英文小短文 + 中文译文，错词自动加粗，结果会缓存可复用
- **写作干货**：四六级替换词、万能句型、按题材生成的范文（可 AI 生成）
- **历史日历**：有记录的日期会标色，点开看当天错词和短文
- **学习时长统计**：自动统计每天在「不背单词」里的时长，柱状图看 7/15/30 天或按月
- **宠物养成**：学习词数 = 经验，7 种形态随等级进化，可对话（AI 按形态切换性格）、每天主动提醒高频词和好词好句
- **两套外观**：默认蓝、星露谷暖木色

## 环境要求

- Android 10（API 29）及以上
- 需要开启「无障碍服务」（这是抓词的前提）
- 需要 DeepSeek API Key（用于生成短文、范文、宠物对话）

## 构建

```bash
# 需要 JDK 11（Android Studio 自带的 jre 即可）
export JAVA_HOME=/path/to/android-studio/jre     # Windows: set JAVA_HOME=...
./gradlew assembleDebug --no-daemon
```

> 本项目使用 AGP 7.1.3 / Gradle 7.2 / compileSdk 31，构建时建议加 `--no-daemon`，
> 否则偶发 `mergeDebugResources` 报 NullPointerException（增量缓存问题，`clean` 可解）。

产物：`app/build/outputs/apk/debug/app-debug.apk`

## 使用步骤

1. 安装 APK，打开 App
2. 侧滑菜单 → 设置 → 填入 DeepSeek API Key（[在这里申请](https://platform.deepseek.com)）
3. 「我的」→ 去开启无障碍服务 → 找到「错词捕手」打开开关
4. 正常用「不背单词」背单词
5. 回到 App 首页看错词 → 点「用这些错词生成短文」

## 已知限制

- 只适配了「不背单词」两类题型（选择题、自评题）；拼写题等暂未支持
- 依赖对方的界面控件 id，App 改版后可能失效
- 部分系统（如小米 HyperOS）会限制无障碍服务，建议给 App 设置「自启动」+「省电无限制」
- 数据全部保存在本机，卸载即丢失

## 隐私

- 所有错词、短文、宠物数据只存本机（应用私有目录）
- 只在生成短文/范文/宠物对话时，把**相关文字**发送给你配置的 DeepSeek 接口
- 不收集、不上传任何其他信息
